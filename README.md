# VELTRIX

Личное пространство для Android и Windows. Планы, привычки, финансы, заметки и события сохраняются в одном аккаунте и доступны на обоих устройствах.

## Что есть в приложении

- **Сегодня:** ближайшие дела, привычки, подсказки и краткий обзор.
- **Помощник:** разговор о планах, голосовой ввод в поддерживаемом браузере, предложение задач и привычек с сохранением в общий план.
- **Мой путь:** цели и шаги на сегодня, неделю, месяц, год и пять лет.
- **Итоги:** выполнение планов, серии привычек и время в фокусе.
- **Жизнь:** таймер работы, запись часов сна и собственный календарь событий.
- **Финансы:** доходы и расходы в тенге, месячный итог и категории трат.
- **База знаний:** 12 коротких подсказок VELTRIX, личные заметки, поиск и категории.
- **Оформление:** три спокойные серые темы и два варианта плотности карточек.

Планы и записи хранятся в Cloudflare D1. История диалога и тема оформления хранятся на конкретном устройстве. Старые задачи первой версии остаются в базе.

Голосовой ввод использует распознавание речи браузера и запрашивает разрешение на микрофон. Для настоящего диалога с моделью подготовлена привязка Cloudflare Workers AI, но `AI_ENABLED` оставлен `false`: текущий API-токен не имеет доступа к Workers AI, а платный режим не разрешён. Пока помощник явно помечает простой разбор текста и предлагает проверить изменения перед сохранением. После подтверждения бесплатного лимита и прав токена можно включить `AI_ENABLED = "true"` в `wrangler.toml` и повторно опубликовать Worker. При недоступности модели приложение возвращается к простому разбору текста.

## Локальная разработка

Нужны Node.js 22.13+ и npm.

```sh
cd /workspace/Maro
npm ci
npm run db:local
npm start
```

Wrangler покажет локальный адрес (обычно порт 8787). `npm test` проверяет интерфейс и реальный локальный Worker с отдельной временной базой, включая регистрацию, сохранение всех разделов, синхронизацию сеансов и изоляцию аккаунтов. Локальные данные Wrangler находятся в `.wrangler/state` и не попадают в Git.

## Публикация

Рабочий адрес: https://veltrix.beibarysbolat0.workers.dev. Старый адрес `maro.beibarysbolat0.workers.dev` перенаправляет на новый. База D1 по-прежнему называется `maro`: аккаунты и записи сохраняются. Повторно создавать базу не нужно. После изменения кода и добавления миграций:

```sh
cd /workspace/Maro
npx wrangler d1 migrations apply maro --remote
npx wrangler deploy
```

При необходимости перенаправление со старого адреса обновляется командой `npx wrangler deploy --config redirect/wrangler.toml`.

Для этих команд среда должна предоставлять `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN` с правами D1 и Workers Scripts. Не храните токен в репозитории. Обновление приложения использует существующую базу и аккаунты.

На Android откройте сайт в Chrome и выберите установку из меню браузера. На Windows используйте Chrome или Edge. Если браузер не предлагает установку, сайт работает как обычная веб-страница.

## Ограничения

При выключенном Workers AI помощник использует простой разбор текста и не поддерживает полноценную беседу. Календарь и сон заполняются вручную: синхронизация с Google Calendar и данными здоровья Android требует отдельного разрешения и подключения внешних сервисов. Таймер сохраняет завершённый блок, но текущий отсчёт не переносится между устройствами. Валюта финансового раздела сейчас тенге. Восстановление забытого пароля и push-напоминания ещё не реализованы.
