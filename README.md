# Maro

Личный планировщик для Android и Windows. Один аккаунт показывает одни и те же цели и задачи на обоих устройствах. Планы разделены на сегодня, неделю, месяц, год и пять лет; есть сферы учёбы, работы, здоровья, финансов и личных дел. Помощник предлагает простые шаги по шаблонам и на основе цели более длинного срока. Пользователь решает, добавлять ли предложение.

## Проверить локально

Нужен Node.js 22.13+ и npm. Проверено на Node.js 24.19.

```sh
cd /workspace/Maro
npm ci
npm run db:local
npm run dev:cloud
```

Откройте локальный адрес, который напечатает Wrangler (обычно порт 8787). `npm test` проверяет отдельный Node.js сервер с тем же интерфейсом API. Вариант Cloudflare Worker также проверен локальными запросами: регистрация, вход, создание и изменение задачи, синхронизация между двумя сеансами. Для локальной разработки Wrangler хранит базу в `.wrangler/state`; она не добавляется в Git.

Есть также отдельный запуск `npm start` на порту 3000 с SQLite в `.data`. Он помогает быстро работать без Wrangler. Данные между этим вариантом и Cloudflare не копируются автоматически. Используйте один и тот же адрес приложения на обоих устройствах для общего плана.

## Бесплатное размещение через Cloudflare

Для публикации нужен личный аккаунт Cloudflare на бесплатном плане и авторизация Wrangler. Тарифы и лимиты Cloudflare могут меняться; перед публикацией проверьте выбранный план в аккаунте. Для небольшого личного приложения обычно достаточно бесплатного лимита Workers и D1.

1. Создайте аккаунт Cloudflare и включите адрес `workers.dev` в его панели.
2. Для автоматической публикации из облачной среды создайте API token с разрешениями **Workers Scripts: Edit**, **D1: Edit**, **Account Settings: Read** для своего аккаунта. Укажите токен только в секретных настройках среды как `CLOUDFLARE_API_TOKEN`, а ID аккаунта как обычную переменную `CLOUDFLARE_ACCOUNT_ID`. Никогда не присылайте токен в чат и не добавляйте его в Git.
3. После появления этих переменных в рабочей среде выполните из каталога проекта `npx wrangler d1 create maro`. Команда выдаст `database_id`. Подставьте его вместо нулевого ID в `wrangler.toml`.
4. Выполните `npx wrangler d1 migrations apply maro --remote`, затем `npx wrangler deploy`. Проверьте адрес, выданный Wrangler: откройте страницу, зарегистрируйтесь, добавьте задачу и войдите в тот же аккаунт на втором устройстве.
5. На Android в Chrome выберите установку приложения из меню браузера. На Windows используйте установку в Chrome или Edge. Если браузер не предложит установку, сайт всё равно будет работать.

Опубликованные данные хранятся в D1 Cloudflare. Локальная база не выгружается при публикации. Размещение пока **не выполнено**: без аккаунта Cloudflare и его доступа команды создания базы и публикации не пройдут.

## Ограничения первой версии

Предложения строятся по простым правилам; ИИ-чата и push-напоминаний пока нет. Дату и название задачи можно менять, область и срок — при создании. Для работы и синхронизации требуется интернет. Для публичного использования с большим числом пользователей нужно добавить защиту от массовых попыток входа и процедуру восстановления пароля.
