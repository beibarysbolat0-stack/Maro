# VELTRIX

Личное пространство для Android и Windows. Планы, привычки, финансы, заметки и события сохраняются в одном аккаунте и доступны на обоих устройствах.

## Что есть в приложении

- **Входящие:** быстрые задачи без выбранной даты.
- **Проекты и поиск:** группировка задач по проекту, поиск по задачам, меткам, привычкам и заметкам.
- **Подпункты:** чек-лист внутри задачи, доступный на всех устройствах.
- **Повторяющиеся задачи:** ежедневные, еженедельные и ежемесячные дела создают новую запись на соответствующий день при открытии приложения.
- **Метки и приоритет:** собственные метки, выделение важных задач и фильтры доски.
- **Сегодня:** только задачи с сегодняшней датой, привычки, подсказки и краткий обзор. В полночь план обновляется; прошедшие дневные дела остаются в разделе «Архив → История дней» и календаре.
- **Календарь:** просмотр дня, недели и месяца, расписание по часам, задачи со временем и длительностью, собственные события.
- **Доска:** задачи по этапам «Запланировано», «В работе», «Готово», фильтр по сфере и проекту, цветные карточки и перенос мышью или кнопками.
- **Привычки:** отметки по дням недели, текущая и лучшая серии, показатели за неделю, месяц и год.
- **Архив:** временно убирает задачи и привычки из активных планов с возможностью восстановления.
- **Помощник:** разговор о планах, голосовой ввод в поддерживаемом браузере, предложение задач и привычек с сохранением в общий план.
- **Мой путь:** цели и шаги на сегодня, неделю, месяц, год и пять лет.
- **Итоги:** выполнение планов, серии привычек и время в фокусе.
- **Жизнь:** таймер работы, запись часов сна и собственный календарь событий.
- **Финансы:** доходы и расходы в тенге, месячный итог и категории трат.
- **База знаний:** 12 коротких подсказок VELTRIX, личные заметки, поиск и категории.
- **Оформление:** тёмно-серая тема по умолчанию и две светлые темы и два варианта плотности карточек.

Планы и записи хранятся в Cloudflare D1. История диалога и тема оформления хранятся на конкретном устройстве. Старые задачи первой версии остаются в базе. Новые поля и подпункты добавлены миграциями `0004_workspace.sql` и `0005_tasks.sql`; Wrangler применяет их вместе с остальными.

Голосовой ввод использует распознавание речи браузера и запрашивает разрешение на микрофон. Распознанные задачи и привычки автоматически сохраняются, если включён переключатель автосохранения в разделе помощника; переключатель можно выключить для проверки черновика. Диалог использует модель Cloudflare Workers AI `@cf/meta/llama-3.1-8b-instruct-fp8` в бесплатной дневной квоте. Сервер ограничивает вызовы модели 20 запросами в сутки для всего приложения. Когда лимит достигнут или модель недоступна, помощник явно помечает простой разбор текста. Чат хранится на текущем устройстве, а задачи и привычки синхронизируются через аккаунт.

## Локальная разработка

Нужны Node.js 22.13+ и npm.

```sh
cd /workspace/Maro
npm ci
npm run db:local
npm start
```

Wrangler покажет локальный адрес (обычно порт 8787). `npm test` проверяет интерфейс и реальный локальный Worker с отдельной временной базой, включая регистрацию, сохранение всех разделов, синхронизацию сеансов и изоляцию аккаунтов. Локальные данные Wrangler находятся в `.wrangler/state` и не попадают в Git.

## Публикация

Рабочий адрес: https://veltrix.beibarysbolat0.workers.dev. Старый адрес `maro.beibarysbolat0.workers.dev` перенаправляет на новый. База D1 по-прежнему называется `maro`: аккаунты и записи сохраняются. Повторно создавать базу не нужно. После изменения кода и добавления миграций:

```sh
cd /workspace/Maro
npx wrangler d1 migrations apply maro --remote
npx wrangler deploy
```

При необходимости перенаправление со старого адреса обновляется командой `npx wrangler deploy --config redirect/wrangler.toml`.

Для этих команд среда должна предоставлять `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN` с правами D1 и Workers Scripts. Не храните токен в репозитории. Обновление приложения использует существующую базу и аккаунты.

На Android откройте сайт в Chrome и выберите установку из меню браузера. На Windows используйте Chrome или Edge. Если браузер не предлагает установку, сайт работает как обычная веб-страница.

## Ограничения

Бесплатный лимит Workers AI общий для аккаунта Cloudflare: если его используют другие приложения, доступность модели зависит и от них. Календарь и сон заполняются вручную: синхронизация с Google Calendar и данными здоровья Android требует отдельного разрешения и подключения внешних сервисов. Таймер сохраняет завершённый блок, но текущий отсчёт не переносится между устройствами. Валюта финансового раздела сейчас тенге. Уведомления о задачах работают с разрешения браузера, пока приложение открыто; фоновые push-уведомления при закрытом приложении ещё не реализованы. Восстановление забытого пароля тоже пока недоступно.
