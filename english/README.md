# LingoStep

Отдельное бесплатное веб-приложение для изучения английского на Android и Windows. Курс рассчитан на человека, который уже знает простые слова и фразы. Он содержит 10 коротких уроков уровня A1–A2, 200 разных слов и выражений (около 20 в каждой теме), диалоги, вопросы, карточки с повторением, тренировку произношения и 10 собственных видеоуроков с английской озвучкой, русскими субтитрами и паузой для ответа.

Откройте опубликованный адрес `https://veltrix-english.beibarysbolat0.workers.dev`. На Android сайт можно установить через меню Chrome, на Windows — через Chrome или Edge. Озвучивание использует синтез речи браузера; распознавание голоса доступно, если его поддерживает браузер и пользователь разрешил микрофон. При отсутствии микрофона фразу можно ввести вручную.

Каждый день при открытии приложения появляется следующая подборка из 10 новых слов. Если пропустить день, слова не пропадают: следующая подборка ждёт возвращения. После 20 подборок словарь курса заканчивается, а изученные слова остаются в уроках и повторении.

Прогресс автоматически хранится в браузере конкретного устройства. В разделе «Прогресс» есть скачивание и загрузка файла для ручного переноса между телефоном и ноутбуком. Аккаунта и автоматической синхронизации в этой версии нет. Уроки и упражнения доступны без оплаты; после первого успешного открытия основные файлы кэшируются для работы без сети. Видео воспроизводятся непосредственно в уроках и в разделе «Видео». Их озвучка синтезирована локальным свободным движком Flite при сборке, а для просмотра видеоклипов требуется интернет.

Локальная проверка из корня репозитория: `node --test english/test/app.test.js`. Для публикации из корня репозитория: `npx wrangler deploy --config english/wrangler.toml`. Публикуется отдельный Cloudflare Worker со статическими файлами и без D1, Workers AI или платных ресурсов.

## Сборка видео

Оригинальные MP4 и обложки уже включены в репозиторий. Для пересборки после изменения курса нужны Python 3 с Pillow, Node.js и FFmpeg с фильтром Flite: `python3 english/scripts/build_videos.py` из корня репозитория. Генерация не обращается к внешним видеосервисам.
